# ShpTo3DTiles 1.1.0 source code

This folder contains the source snapshot used with the `release-1.1.0` package.

- `pom.xml` — Maven build configuration
- `src/main` — application source code and resources
- `src/test` — source tests

Build from this folder with:

```powershell
mvn clean package
```

The runnable Windows package remains in the sibling `ShpTo3DTiles` folder.
